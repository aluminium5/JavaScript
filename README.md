## 🚀 Practical Overviews

### 🔹 [Practical 1: JavaScript Basics & Console Methods](./Prac1/)
- **Concepts Covered:** Inline, internal, and external JavaScript integration, debugging via `console.log()`, `console.warn()`, `console.error()`, `console.table()`.
- **Applications:**
  - `index.html`: SIT Nagpur CSE Department landing webpage.
  - `student.html`: Student Information Portal with GPA validation.

### 🔹 [Practical 2: ES6 Syntax & Billing Calculators](./Prac2/)
- **Concepts Covered:** Scope differences between `var`, `let`, and `const`, template literals (string interpolation), array/object destructuring.
- **Applications:**
  - `index.html` / `gst_calculator.js`: Interactive GST and billing calculator.
  - `Prac2_shoppingweb/`: Full e-commerce cart interface with tax calculations.

### 🔹 [Practical 3: Control Structures & Validation](./Prac3/)
- **Concepts Covered:** Conditional logic (`if-else`, `switch`), loops (`for`, `while`), form input verification.
- **Applications:**
  - `Grade-check/`: Dynamic Grade Calculator based on percentage inputs.
  - `Password/`: Password strength analyzer checking length, numbers, and special characters.

### 🔹 [Practical 4: Functions, Closures & Exception Handling](./Prac4/)
- **Concepts Covered:** Function declarations, arrow functions, lexical scope, closures, error handling with `try-catch-finally`.
- **Applications:**
  - `Palindrome/`: Real-time string & numeric Palindrome checker.
  - `Vehicle-Registration/`: Vehicle registration code format validator using custom error handling.

### 🔹 [Practical 5: Arrays, Objects & ES6 Array Methods](./Prac5/)
- **Concepts Covered:** JavaScript objects, nested arrays, higher-order array methods (`map()`, `filter()`, `reduce()`, `find()`).
- **Applications:**
  - `Prac5.1/AtharvCart/`: Interactive shopping cart using `reduce()` for subtotal/total calculations.
  - `Prac5.2/`: Student Marks Analyzer finding highest and lowest scorers using `Math.max()`/`Math.min()` and `map()`.

### 🔹 [Practical 6: String Methods & Regular Expressions](./Prac6/)
- **Concepts Covered:** String methods (`split()`, `replace()`, `indexOf()`, `trim()`), Regex pattern creation (`test()`, `match()`), input sanitization.
- **Applications:**
  - `6.1/`: String & Regex workbench validating email patterns and replacing text.
  - `6.2/`: Text reverser and detailed vowel frequency analyzer (`a`, `e`, `i`, `o`, `u`).

### 🔹 [Practical 7: Dynamic DOM & Advanced Events](./Prac7/)
- **Concepts Covered:** Document Object Model (DOM) tree traversal, dynamic element creation (`createElement`, `appendChild`, `remove`), event handling, client-side validation.
- **Applications:**
  - `Prac7.1/`: Interactive Task Manager (To-Do List) with inline edit and deletion.
  - `Prac7.2/`: Comprehensive user registration form with real-time field error highlighting and validation.

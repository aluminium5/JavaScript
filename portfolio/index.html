About me

I am a Computer Science undergraduate at Symbiosis Institute of Technology, Nagpur, specialising in Artificial Intelligence & Machine Learning and currently in my fifth semester. Alongside that I build for the web — the part of the stack a person actually touches.

I like learning a language by building with it rather than reading about it. Every concept from my JavaScript laboratory became a small, complete application: closures became a vehicle registration validator, reduce() became a shopping cart, regular expressions became an email and password checker, and the Fetch API became a live student records table.

This portfolio is itself part of that practice. It is written in hand-rolled HTML, CSS and vanilla JavaScript — the project cards below are rendered with map(), filtered with filter(), revealed with IntersectionObserver, and the theme you are reading it in is remembered using localStorage, exactly as taught in Practical 9.
